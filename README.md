# Revit API — Early Projects Archive

This repository preserves my first Revit API exercises from 2024. It documents the beginning of my BIM automation journey and the progression from small task-focused tools to larger Revit plugins.

> **Archive notice:** These projects are kept for historical and learning purposes. They are not actively maintained.

## Early projects

| Project | Purpose |
|---|---|
| NumberAir | Number air systems |
| NumberPipesActiveView | Number pipes in the active view |
| NumberColumns | Number structural columns |
| WallVolume | Calculate wall volumes |
| PipeLength | Calculate pipe lengths |
| PipeLengthCoeff | Calculate pipe lengths using a coefficient |
| ModifyPipeName | Modify pipe names |

## Technologies

- Autodesk Revit
- Revit API
- C#
- .NET
